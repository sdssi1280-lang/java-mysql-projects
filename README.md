# Java + MySQL Projects

A collection of beginner-friendly Java projects integrated with MySQL databases using JDBC.

## Projects

### Hospital Management System

A Java and MySQL-based hospital management system that allows users to:

- Register new patients
- Search for existing patients using their phone number
- Select a medical department
- Assign the appropriate doctor
- Book appointments
- Store patient and appointment information in a MySQL database

## Technologies Used

- Java
- MySQL
- JDBC (Java Database Connectivity)
- BlueJ
- MySQL Workbench

## Database Tables

The Hospital Management System currently uses three MySQL tables:

- `patients`
- `doctors`
- `appointments`
